# Cosmic Heroes of Steel Museum

An interactive educational space museum about the legacy of NASA's inactive, retired, and left-behind exploration hardware.

## Museum experience

Opening story → Solar System overview → Destination → NASA mission marker → Mission preview → Hero of Steel exhibit → Legacy Gallery.

The map covers the Solar System, including archive-only missions. The initial goal is **six complete Hero of Steel exhibits**, with other documented missions remaining discoverable as shorter archive entries.

## Design commitments

- Original Cosmic Heroes identity; no NASA logo or implied NASA endorsement.
- Centered museum title, clear typography, straight-edged or lightly softened controls.
- Real NASA mission evidence, coordinates, photographs, and clear credits.
- Lightweight HTML, CSS and vanilla JavaScript; Three.js only where 3D is valuable.
- Responsive, keyboard-accessible, low-bandwidth-conscious presentation.
- Calm motion, no excessive gradients or decorative visual noise.
