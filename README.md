# Cosmic Heroes of Steel Museum

An interactive digital science museum celebrating humanity's robotic explorers across the Solar System. Built with React, TypeScript, Vite, and Three.js.

## Overview

- **Entrance Gallery:** Velvet curtain opening sequence, original museum identity, and optional voice narration via Web Speech API.
- **Exploration Hall (Solar System):** Interactive 3D Solar System built with Three.js featuring Sun glow, corona, eight planets with orbit paths, moons, rings, atmospheric shells, asteroid belt, and Pluto, with pointer drag-rotation, zoom, camera focus, and resilient 2D WebGL fallback.
- **The Museum Collection:** Detailed registry of historical explorers (Surveyor 3, Apollo 15 LRV, Sojourner, Opportunity, InSight, Pioneer 10).
- **Destination Exploration Views:** Curated regional exploration for the Moon, Mars, and Deep Space.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
