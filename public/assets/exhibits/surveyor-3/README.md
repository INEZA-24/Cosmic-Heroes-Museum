# Surveyor 3 — exhibit images

Upload a historical lunar lander photograph as `hero.webp` (or tell us the actual extension if using JPG/PNG). Optional story images: `story-01.webp`, `story-02.webp`. Preserve image sources and credits. Surveyor 3 will initially use an image-only display; no GLB required.

The `slides.json` manifest will be created when the exhibit is implemented, after the final images are available.
