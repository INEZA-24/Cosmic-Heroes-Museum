# Surveyor 3 — Stella's narration recordings

Upload the first completed recording here as:

- `scene-01.mp3` — Stella's historical hook, from Yuri Gagarin's first spaceflight to the question of landing on the Moon.

Keep later recordings in this same folder: `scene-02.mp3`, `scene-03.mp3`, and `scene-04.mp3`, as each scene is approved and produced.

This folder contains *voice recordings only*. The museum narration UI does not yet play these MP3 files automatically; connecting the recordings and their scene-by-scene auto-scroll timings will be a separate implementation once we have the final audio.

For high-quality, lightweight web delivery, prefer mono or stereo MP3 at 128–192 kbps. Preserve the raw source audio separately if available. Do not commit API keys or voice-service credentials.
