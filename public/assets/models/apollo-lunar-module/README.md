# Apollo Lunar Module — supporting 3D model

Upload the official NASA Apollo Lunar Module GLB here as **`model.glb`**.

This is a generic Apollo Lunar Module model representing the design, not an authenticated 3D reconstruction of the Apollo 15 *Falcon*. It will be featured inside the existing Apollo 15 LRV exhibit; do not create a separate main exhibit.

Associated images belong in the **existing** `public/assets/exhibits/apollo-15-lrv/` folder, e.g. `falcon.webp`, `falcon-rover.webp`, `falcon-astronaut-rover.webp`.
