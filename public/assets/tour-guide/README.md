# Museum tour guide assets

Upload the transparent-background PNG illustrations here, using these filenames:

- `neutral-hands-clasped.png` — neutral dialogue and introductions
- `welcome-wave.png` — welcome and goodbye messages
- `presenting-one-hand.png` — showing a mission or navigation action
- `explaining-two-hands.png` — narrating discoveries or key facts

These assets will be connected to the museum guide dialogue component in a subsequent change. Keep filenames lowercase and unchanged so code can reference `/assets/tour-guide/<filename>.png`.
