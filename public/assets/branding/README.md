# Museum identity assets

Place the approved standalone museum emblem here (prefer a transparent-background PNG or SVG).
Suggested filename: `museum-emblem.png`.

Keep original artwork and credit/source information. A full poster containing text is **not** a suitable header icon; use a standalone emblem, ideally square, with the correct museum spelling "COSMIC HEROES OF STEEL MUSEUM".
The site automatically displays `museum-emblem.png` in the entrance and header once you upload it. Until then it uses the original star placeholder. Do not upload the entire poster as this small logo; use the isolated rover-and-orbit emblem with correct lettering if any.
